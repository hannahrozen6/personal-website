# personal-website
This repository contains the source code and Markdown files for my personal website, which features my portfolio, resume, and contact information.

**Live Link:** [https://hannahrozenbaum.netlify.app/]

## Features
*   **Homepage:** A brief introduction about my background and technical interests.
*   **Portfolio:** A showcase of my coding and data science projects.
*   **Data Visualization & Creative Work:** A collection of my data visualization projects and creative work.
*   **Socio-Technical Risk Assessments:** Essays and written work relating to AI policy, algorithmic governance, and socio-technical auditing.
*   **Resume:** An updated, web-accessible version of my professional experience.
*   **Contact:** Direct links to reach out to me via email or professional socials.

## Built With
*   **Framework:** [Quarto](https://quarto.org/) (Markdown-based publishing system)
*   **Deployment & Hosting:** [Netlify](https://www.netlify.com/) (Connected via continuous deployment from GitHub)

## 📁 Repository Structure
*   `_quarto.yml`: The configuration file controlling the website navigation, theme, and structure.
*   `index.qmd`: The homepage of the website.
*   `projects.qmd`: The project showcase page.
*   `data-vis-and-creative-work.qmd`: A page dedicated to data visualization and creative work.
*   `resume.qmd`: My professional resume page.
*   `essays.qmd`: A page containing essays and written work relating to algorithmic bias and ethics.
*   `contact.qmd`: The contact information page.
*   `assets/`: Directory containing images, reports, and other static assets.
